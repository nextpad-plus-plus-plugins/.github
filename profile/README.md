This organization hosts the source and signed releases for every plugin that extends **Nextpad++**. Each one is ported from the Notepad++ ecosystem and rebuilt natively — compiled as a `.dylib` on macOS and a `.so` on Linux (GTK4), per-architecture and checksum-verified. Every plugin is free and open source under **GPL-3.0**.

**62 plugins on macOS · 29 native on Linux · more added every release.**

## Install

**The easy way — inside Nextpad++:** open **Plugins → Plugins Admin**, find the plugin in the **Available** tab, and click **Install**. The host downloads the correct build for your OS and architecture, verifies its checksum, and loads it. The **Updates** and **Installed** tabs upgrade or remove what you have.

**Manual:** download the release `.zip` from any plugin's repository in the table below and install it into your Nextpad++ plugins folder.

Step-by-step instructions for both platforms are on the [plugin catalog page](https://nextpad.org/plugins/).
